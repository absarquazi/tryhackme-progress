I wanted to keep my TryHackMe progress on GitHub too, so I decided to build a small automation for it.

Now, whenever I complete a room, I can run one command (./add-room.sh "------") or (thm "------") and it:
• Adds the room to my progress
• Creates a Git commit
• Pushes the update to GitHub
I tested it with Defensive Security Intro, and it worked.

It’s a small project, but I got to practice Bash, Git, GitHub, and automation while building something I actually wanted for myself.
I’ve now started Linux Fundamentals Part 1 on TryHackMe, and I’ll be using the same setup to keep my progress updated on GitHub as I continue.
